Subnet incentive history

See how incentive moves across a subnet's UIDs.

Pick a subnet and this site asks the configured GraphQL provider for its incentive history, keeps the points that parse cleanly and draws one line per UID.

What happens when you plot

  1. One GraphQL requestA subnets(netUid) query for every UID's incentive series, with a {{ timeout|floatformat:"-1" }}s timeout.
  2. Points are checkedMissing, negative, non-numeric or unparseable entries are dropped instead of breaking the chart.
  3. A chart is drawnThe {{ max_plotted }} UIDs with the highest latest value get a line; the rest are counted.
  4. The result is reusedEach subnet's chart is cached for {{ cache_seconds }} seconds. Failed requests are never cached.
